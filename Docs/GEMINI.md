# Directrices de Desarrollo (Spec-Driven Development)
- Idioma principal de interacción y documentación: Español (es-419).
- Antes de escribir cualquier línea de código, exige una especificación (`constitution` y `specify`).

# Comandos de Barra Disponibles (/)
- `/analizar` : Ejecuta el grafo de conocimiento local via `npx gitnexus analyze`.
- `/enjambre` : Invoca el clúster de agentes de Ruflo para tareas masivas (`claude-flow work`).
- `/plan`     : Genera un plan de ingeniería SDD usando ECC antes de codificar.
- `/verificar`: Ejecuta las pruebas automatizadas y realiza un análisis de impacto de cambios.
- `/optimizar`: Ejecuta el optimizador de prompts JSON interno.
